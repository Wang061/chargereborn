# 电池数据集采集指南 (DATASET_GUIDE)

> 用 Brain 板 OV2640 + 采集页(连拍)给电池识别模型攒数据。写一次,扩新电池类复用。
> 配套:训练 `ai/esp-detection/espdet_run.py`;板上推理 `components/ai`。

## 0. 一句话原则
- **训练图要像"机器真跑时相机看到的样子"**(同相机、同光照背景最准)。
- **转电池 ＞ 转相机;多样性 ＞ 纯数量。**

## 1. 先备齐
- 板子通电、热点 `chargereborn` 起着、相机正常。
- 一台设备连 `chargereborn`/`12345678`(电脑批量下载更省事;手机把下载设自动)。
- 样本:同一型号,多颜色/多牌子/新旧各几节(5-10 节不同的最好)。
- 2-3 种背景(纯色/桌面/杂乱)+ 可调光照(台灯/顶灯/侧光)。
- dev 机上建类文件夹收图,如 `data/<类名>/`。

## 2. 采集操作(采集页)
1. 浏览器开 `http://192.168.4.1/`。
2. 「类名」填型号(英文/数字,如 `7hao`/`AAA`,会进文件名)。
3. 「间隔」1~1.5s → 「连拍开始」→ 每隔 N 秒自动抓拍 + 下载。
4. ⚠️ 连拍时**手别停**:持续转电池 / 挪位置 / 换光,否则全是重复废帧。
5. 单张用「抓拍」。文件名 `类名_时间戳.jpg` → 收进类文件夹。
6. 浏览器「识别」开关不影响抓拍(抓的是原始帧)。

## 3. 多样性清单(每轴都覆盖)
| 轴 | 怎么变 | 重要度 |
|---|---|---|
| 电池姿态 | 横/竖/斜/任意旋转 | ★★★ |
| 画面位置 | 左中右上下 | ★★★ |
| 远近大小 | 近/中/远(别小成点、别怼满出框) | ★★ |
| 光照 | 强/中/弱/侧光/不同色温 | ★★ |
| 背景 | ≥2-3 种 | ★★ |
| 电池本身 | 不同颜色/牌子/新旧磨损 | ★★ |
| 相机角度 | 适度,偏俯视(向最终部署靠) | ★ |
| 空背景图 | 10-20% 无电池的桌面/墙(压误检) | ★★ |

## 4. 数量 + 红线
- 最少 60-80 张跑通;**150-200+ 才稳**。
- 一张一颗电池(每张一个框,好标注)。
- 🔴 鼓包先不拍;真要拍别戳/压/加热锂电(用已鼓的电子垃圾或替代物)。异常识别是 MVP 之后单独加(二分类 / 异常类);安全主力是三传感器,不是视觉。

## 5. 拍完 → 下一步
1. 同类一个文件夹,放到 dev 机。
2. 标注:画框(YOLO 格式)—— LabelImg 手标 或 自动框 + 人工修。
3. train/val 划分 + dataset yaml + calib 集。
4. 训练:`espdet_run.py`(chargereborn conda env)→ `.espdl`。
5. 部署:`.espdl` + 部署包 vendored 进 `components/ai`,换占位猫 + 改 `ai_class_name` 表 → build → flash → 浏览器实测。

## 6. 扩展(以后)
- 加新型号 = 新类:每类同样按本指南拍一批,合并训练。
- 异常(鼓包/漏液):单独拍或单独二分类,见 §4 红线。

## 7. 第二轮补拍(2026-06-17,治"框合并/置信度低/慢")

> 第一轮 78 张(一张一颗)证明了链路,但暴露三问题:**多颗合并成一框、置信度仅 0.3-0.4、推理偏慢**。
> 前两者根因 = **训练集全是"一张一颗"+量少**;第三者要靠重训更小输入。下面这轮一起治。

### 7.1 一定要补的(关键)
- 🔴 **多颗同框**:很多张里放 **2-4 颗 18650**——分开的、挨着的、十字交叠的、各自不同朝向。**这是治"合并成一个框"的唯一办法**(模型得见过"多颗"才会分开框)。占新拍的一半以上。
- **仍保留单颗**:单颗也继续拍一些(混着来),别全是多颗。
- **总量**:新拍 **120-150 张**,和旧的合计 **200+**(量越大置信度越稳)。
- 多样性照旧(§3):角度/位置/远近/光照/背景/不同电池,只是现在"每张颗数"也成了一个要变的轴。

### 7.2 数量配比建议(新拍 ~130 张)
| 类型 | 张数 | 说明 |
|---|---|---|
| 2 颗同框 | ~45 | 分开 / 挨着 / 交叠各来点 |
| 3-4 颗同框 | ~35 | 模拟"一堆里挑" |
| 单颗 | ~35 | 保持单颗能力 |
| 空背景 | ~15 | 继续压误检 |

### 7.3 标注(用升级版工具,支持一张多框)
