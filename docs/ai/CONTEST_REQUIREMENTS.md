# 竞赛作品提交要求（全国大学生嵌入式芯片与系统设计竞赛 · 应用赛道）

> 来源:乐鑫官方赛题页 + 大赛组委会 socchina.net「2026年应用赛道作品上传要求」(2026-06-04)。
> 抓取于 2026-06-24。投稿前以官网最新通知为准。

## 关键时间节点
| 事项 | 截止 |
|---|---|
| 报名信息修改（含**作品名称及简介**、团队成员） | **2026-06-30 24:00** |
| **作品提交** | **2026-07-09 18:00** |

## 必交材料（3 项）
1. **作品介绍视频** — MP4，**总时长 ≤3 分钟**（含大赛统一封面 ≤2 秒），**≤300M**。重点放作品演示，切忌全程 PPT 讲解。
2. **作品设计报告** — PDF，**≤50M**，按官方模板（章节见下）。
3. **作品重要代码**。

> "作品简介"是报名系统里的一个字段（随报名信息，6/30 前可改），官方**未给字数限制**；正式长文走"设计报告"的**摘要(≤800字)**。

## ⚠️ 硬性禁令（违反取消资格）
- 报告、视频**均不得出现学校名称、指导老师信息**等字样。
- 自制 PCB 丝印须印大赛口号 **"AI for Design, Design for AI"** + 加工时间，且**不得出现学校/老师/学生姓名**。

## 芯片约束（我们符合 ✓）
- 主控**必须** ESP32-P4 或 **ESP32-S3**（二选一）。
- **主要功能代码必须运行在乐鑫芯片上**；若主要功能由第三方芯片实现 → 判违规选题。
  - 本项目 AI 推理全程跑 S3（esp-dl），正中要求。

## 设计报告模板章节（含字数上限，逐条对齐）
- **摘要** ≤800 字
- **第一部分 作品概述**
  - 功能与特性 ≤400 字（可加图）
  - 应用领域 ≤400 字（可加图）
  - 主要技术特点 ≤400 字
  - 主要性能指标 ≤200 字（建议表格）
  - 主要创新点 ≤200 字（逐点）
  - 设计流程 ≤200 字（可加图）
- **第二部分 系统组成及功能说明**（图文结合）
  - 整体框图 + 各子模块关系
  - 硬件:整体 / 机械设计 / 电���各模块（SCH/PCB 截图）
  - 软件:整体（含 PC/云端）/ 各模块（流程图 + 关键输入输出）
- **第三部分 完成情况及性能参数**（实物照片为主）
  - 整体实物（正面 + 斜 45°）/ 机械成果 / 电路成果 / 软件界面 / 量化指标
- **第四部分 总结**
  - 可扩展之处 ≤300 字
  - 心得体会 ≤1000 字
- **第五部分 参考文献** ≤20 篇

## 评分维度（组委会未在上传通知给权重；综合各分赛区通知）
完成度、创新性、难度、系统功能与指标、答辩情况;资格审核另看工程可行性、平台适用度。
