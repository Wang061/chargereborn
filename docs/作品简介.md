# ChargeReborn 作品简介（报名系统字段版）

ChargeReborn 是一套面向退役锂电池安全回收的边缘智能预处理系统。它瞄准当前废旧锂电池拆解环节高度依赖人工目检、型号识别效率低、且存在短路与热失控隐患的痛点，把电池识别与定位这一核心环节的 AI 推理**完全收敛到乐鑫 ESP32-S3 芯片上离线运行**，主要功能代码与 AI 推理均跑在乐鑫芯片，无需联网与云端算力。

目前已在 ESP32-S3 上完成并实测打通整条边缘 AI 主轴：

- **芯片端实时识别**：基于乐鑫 ESP-DL，在 S3 上离线运行自训练的 ESPDet-Pico 检测模型，实时框出电池型号与置信度，支持画面中多颗电池同时分框。
- **自建数据与自训模型**：团队自采多角度电池数据集并完成标注，从零训练检测模型（浮点 mAP50 达 0.96），再经 int8 + letterbox 量化部署到芯片端，实现板载实时推理。
- **图传与数据采集**：S3 以 WiFi 自建热点提供网页端实时图传与连拍采集页，既是演示界面，也是采集训练数据的工具。
- **可视化识别**：网页端通过 `/detect` 接口实时叠加检测框、类别与置信度，识别结果一目了然。
- **姿态估计**：在识别基础上，用结构张量估计每颗电池的长轴角度（对包皮颜色与光照变化鲁棒），网页端叠加角度标线，为后续机械臂抓取提供朝向信息。
- **执行接口**：自研 armlink 模块从识别结果中选取最佳目标，解算出抓取目标（像素中心 + 角度）并经 `/arm_target` 接口与舵机串口协议输出，为机械臂分拣预留标准化通信接口（默认关闭、不驱动实物，保障调试安全）。
- **工程可复现**：依赖锁版、模型随仓入库，克隆即可编译复现，识别结果无漂移。

整套系统围绕"芯片端识别 → 定位 → 执行接口"构成"感知—决策—执行"链路。相比依赖外部视觉模组或上位机算力的传统方案，本作品将识别与定位完全落在乐鑫芯片，兼具低成本、低功耗与数据本地化优势，可为退役电池的型号分选、安全拆解与梯次利用提供前端识别支撑，具备清晰的产业落地价值。
