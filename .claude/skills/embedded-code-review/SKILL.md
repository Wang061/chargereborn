# 嵌入式代码审查清单

**正确性**
- 每个 `esp_err_t` 返回是否检查/处理？关键路径用 `ESP_ERROR_CHECK` 或显式分支+日志。
- 指针/数组边界、整数溢出、有符号/无符号混用。
- 资源：句柄/内存/锁/总线/通道 有申请必有释放（含错误分支）。

**并发/中断**
- 共享数据有保护？ISR 仅用 `*FromISR`、不阻塞、不 ESP_LOGx/malloc。
- 临界区尽量短；无死锁（锁顺序一致）。

**结构/可维护**
- 组件化、驱动与业务分层（rules/coding-standard.md）。
- 统一 TAG + 日志等级；无 magic number（命名常量+单位）。
- 任务创建有栈/优先级理由注释。

**资源约束（嵌入式特有）**
- 栈/堆占用合理；大缓冲走 PSRAM、DMA 缓冲走内部 RAM。
- 避免在热路径频繁 malloc；注意阻塞调用对实时性的影响。

**安全/发版**
- 无硬编码密钥；无调试残留（临时 sdkconfig/打印/延时）。
- 改 sdkconfig/分区/启动 → 走对应 skill + 验证。

输出：按 文件:行 列问题 + 等级（阻断/建议）+ 修法。
